# Наталья Кекова — сайт психолога

Одностраничный статический сайт (HTML + встроенные CSS и JS) о психологической помощи онлайн и очно в Москве. На странице есть встроенный тест; запись на консультацию идёт через WhatsApp и телефон.

- Страница лежит в `public/index.html`, сборки нет.
- Фотографии подгружаются с внешнего CDN (Tilda).
- Хостинг: Netlify, каталог публикации задан в `netlify.toml`.

Чтобы открыть локально, откройте `public/index.html` в браузере.
